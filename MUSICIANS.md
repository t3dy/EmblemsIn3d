## 2. The decision, restated

Sound was turned off on 2026-09-04 and the reasoning stands: this is a reading instrument,
the book's music is *described* rather than notated (the p. 285 passage is ekphrasis reaching
for a thing the page cannot do), and a synthesised nymph-choir would be an invention where the
text is precise about everything except the notes. So the rule is **show it**: instruments in
hands, singers with lips parted, a plaque that names the mode (Iasian, Lydian), the tour note
that describes the counterpoint.
